## Independent findings

### B1 — CONFIRMED CODE BUG — DNS validation is not bound to the connection

- Requirement: REQ-010 condition 4
- Evidence: `src/lib/storage.ts:72-79` validates DNS, but `src/lib/storage.ts:104-109` later calls `fetch(currentUrl)` by hostname. No dispatcher/custom lookup binds the fetch to the approved answer.
- Exploit prerequisites: a provider-controlled output hostname whose DNS answer changes between validation and connection, or a compromised upstream provider returning such a URL.
- Impact: server-side access to private/link-local services and possible response exfiltration into R2.
- Classification: real code bug; HIGH because the violated boundary protects cloud/internal networks, with exploitability conditional on DNS control.

### B2 — CONFIRMED CODE BUG — partial QStash configuration schedules an unusable recovery path

- Requirement: REQ-007, REQ-012
- Evidence: `src/lib/upstash.ts:9-27` treats token + app URL as sufficient and publishes work; the receiver rejects requests unless token plus both signing keys exist at `video-reconcile/route.ts:18-24`.
- Impact: production can accept provider tasks while the advertised durable fallback always returns 503; missed callbacks then retain frozen credits.
- Classification: real code bug; HIGH. Consolidate neither with BUG-002 nor docs because this is a distinct configuration state before the polling loop runs.

### B3 — CONFIRMED CODE BUG — callback body has no application ceiling

- Requirement: REQ-006, REQ-010
- Evidence: `callback/[provider]/route.ts:40` uses `request.json()`; Stripe uses the bounded reader at `webhooks/stripe/route.ts:10-20`.
- Impact: memory/CPU amplification up to any platform limit, and unbounded behavior when self-hosted.
- Disposition: agrees with BUG-004; MEDIUM defense boundary.

### B4 — CONFIRMED DOCUMENTATION BUG — callback secret aliases diverge

- Requirement: REQ-012
- Evidence: executable code reads `CALLBACK_HMAC_SECRET` at `callback-signature.ts:6-13`; README and API guide instruct `AI_CALLBACK_SECRET`.
- Impact: callback URL signing fails at task submission.
- Disposition: agrees with BUG-005; documentation/deployment defect.

### B5 — FALSE POSITIVE — Stripe return destination is not a 404

- Requirement: REQ-009
- Evidence: `src/middleware.ts:11-16`, `34-42`, and matcher `80-84` cover `/dashboard`.
- Disposition: retract BUG-001. The chosen redirect destination remains a product-policy question, not a confirmed security or functional break.
