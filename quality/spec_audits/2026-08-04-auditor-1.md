## Independent findings

### A1 — CONFIRMED CODE BUG — durable recovery stops early

- Requirement: REQ-005, REQ-007
- Evidence: `src/app/api/internal/workflows/video-reconcile/route.ts:28-43` returns `PENDING` after ten attempts; `video-reconcile-failed/route.ts:20-25` only logs.
- Consequence: a missed callback can leave a generation and credit hold nonterminal.
- Disposition: agrees with BUG-002; verify timeout/escalation policy before fixing.

### A2 — FALSE POSITIVE — `/dashboard` is not a missing route

- Requirement: REQ-009
- Evidence: `src/middleware.ts:11-16` defines the redirect and `src/middleware.ts:34-42` executes it before locale middleware.
- Consequence: the payment flow reaches `/text-to-video`, not a 404. Whether it should instead reach `/settings` or `/credits` is a product decision.
- Disposition: retract BUG-001 as written; keep a non-bug policy note.

### A3 — CONFIRMED CODE BUG — exposed creation filters do not affect results

- Requirement: supplemental UI/API consistency contract (REQ-013 proposed)
- Evidence: `src/components/creation/my-creations-page.tsx:29-48` maintains filter state, but `src/hooks/use-videos.ts:30-37` sends only `limit` and `cursor`; `src/lib/api/dashboard-client.ts:49-56` supports only `status`, not model or sort.
- Consequence: changing status, model, or sort triggers a refetch but returns the same unfiltered newest-first page.
- Confidence: high.

### A4 — CONFIRMED CODE BUG — credit history keys disagree across API and UI

- Requirement: supplemental UI/API consistency contract (REQ-013 proposed)
- Evidence: `credit/history/route.ts:21-30` emits lowercase aliases; `credit-history.tsx:19-55` indexes uppercase database names; locale messages use a third set at `src/messages/en.json:559-566`.
- Consequence: normal credit-consume/refund/admin-adjust rows request missing translation keys or fall back to raw identifiers.
- Confidence: high.

### A5 — MISSING TEST, not product bug

- Candidate: CAND-008
- Evidence: no single deterministic paid-generation integration fixture covers auth → validation → freeze → provider → storage → settlement → history.
- Disposition: retain as coverage gap for Phase 5/6; do not inflate bug count.
