## Independent findings

### C1 — CONFIRMED CODE BUG — credit transaction representations have three incompatible vocabularies

- Requirement: REQ-005 plus supplemental REQ-013
- Evidence:
  - database/API input enum: uppercase (`VIDEO_CONSUME`, `REFUND`, `SYSTEM_ADJUST`);
  - API output aliases at `credit/history/route.ts:22-30`: `video_generate`, `video_refund`, `admin_adjust`, `payment_reversal`;
  - UI configuration at `credit-history.tsx:19-55`: uppercase;
  - locale keys at `messages/en.json:559-566`: `video_consume`, `refund`, `system_adjust` and no `payment_reversal`.
- Consequence: credit history can render missing-message errors/raw keys and loses its intended labels/icons.
- Classification: real code bug; MEDIUM.

### C2 — CONFIRMED CODE BUG — creation filters are visually connected but data-disconnected

- Requirement: supplemental REQ-013
- Evidence: UI state is updated at `my-creations-page.tsx:29-48`; the request at `use-videos.ts:30-37` omits all three filter values; client serializer at `dashboard-client.ts:49-56` omits model/sort; service always orders newest at `video.ts:871-876`.
- Consequence: all three controls return the same result set.
- Classification: real code bug; MEDIUM.

### C3 — DESIGN/DOCUMENTATION DEFECT — Bailian's polling-only status is implicit

- Requirement: REQ-011
- Evidence: `bailianParamsTransformer` at `model-mapping.ts:367-406` drops `callbackUrl`; provider still implements `parseCallback` at `bailian.ts:85-87`; ingress list at `callback/[provider]/route.ts:16` excludes Bailian.
- Consequence: the current integration works only through polling, but code cannot mechanically distinguish polling-only from an accidentally omitted callback provider.
- Disposition: keep BUG-003 as a confirmed capability-contract defect, but narrow the expected fix to explicit capability metadata; do not simply add Bailian to ingress unless the vendor supports callbacks.

### C4 — CONFIRMED CONFIGURATION BUG — scheduler/receiver credential parity is broken

- Requirement: REQ-007, REQ-012
- Evidence: `upstash.ts:9-27` vs. `video-reconcile/route.ts:18-24`.
- Disposition: new HIGH bug; agrees independently with Auditor 2.

### C5 — CONFIRMED OPERATIONAL DEFECT — CSP contradicts emitted Vercel components

- Evidence: `layout.tsx:124-125` always renders Analytics and Speed Insights; `next.config.mjs:17` omits `va.vercel-scripts.com`.
- Disposition: agrees with BUG-006; LOW because generation/payment still work.

### C6 — FALSE POSITIVE — missing dashboard route

- Evidence: `middleware.ts:11-16`, `34-42` supplies the legacy route contract.
- Disposition: retract BUG-001 and deprecate its generated patches.
