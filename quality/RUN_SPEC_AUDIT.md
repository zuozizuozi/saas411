# Specification Audit Protocol: VideoFly
> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-08-04 · Project: VideoFly

## Objective

Determine whether each candidate is a code defect, documentation defect, intentional design choice, security hardening opportunity, or false positive. Code is not automatically authoritative when operational documentation defines customer or financial behavior.

## Evidence Set

- `quality/EXPLORATION.md`, `REQUIREMENTS.md`, `CONTRACTS.md`, `QUALITY.md`
- `docs/project-blueprint.md`, `docs/VIDEO-OPERATIONS.md`, `docs/security-payment-operations.md`
- `docs/spec/AI_PROVIDER_INTEGRATION.md`, `docs/spec/CREDIT_CALCULATOR.md`
- `.env.example`, `README.md`, `docs/API-INTEGRATION-GUIDE.md`
- Code-review results and mechanical receipts

## Independent Council Reviews

Run three independent passes and save them under `quality/spec_audits/`:

1. Product/operations reviewer: normal-use and recovery contracts.
2. Security/financial reviewer: auth, ownership, webhooks, SSRF, idempotency, credit value.
3. Implementation consistency reviewer: UI/API/schema/provider/route/config parity.

Each reviewer reports per candidate: CONFIRMED CODE BUG, DOCUMENTATION BUG, DESIGN DECISION, HARDENING, FALSE POSITIVE, or INSUFFICIENT EVIDENCE; exact citations; requirement; consequence; confidence; and required verification probe.

Do not treat missing search results as proof. Resolve disagreements with an executable assertion against current source or a disposable runtime; a rejection requires a passing assertion and a confirmation requires a failing assertion. ```

## Required Candidate Questions

- CAND-001: What is the canonical post-payment route and locale policy? Does `/dashboard` exist in any deploy rewrite?
- CAND-002: What is the maximum supported provider latency? Is admin/user polling an accepted durable completion mechanism?
- CAND-003: Is Bailian polling-only by contract, or is callback ingress incomplete?
- CAND-004: What body limit applies to AI provider callbacks and does platform infrastructure impose an earlier bound?
- CAND-005: Does the deployed HTTP stack pin DNS or otherwise close the validation/fetch gap?
- CAND-006: Which callback-secret name is current, and which guides are production-facing?
- CAND-007: Are Vercel Analytics and Speed Insights intentionally enabled in production?
- CAND-008: Which integration environment can prove the paid-generation state machine without customer impact?

## Verification Probe Rule

Disagreements require executable evidence. Route claims use a production manifest/request. Enumeration claims use `quality/mechanical/` extraction. State-machine claims use a deterministic provider fixture and ledger assertions. Security infrastructure claims require deployment configuration evidence; do not resolve them from assumptions.

## Triage Output

Produce `quality/spec_audits/YYYY-MM-DD-triage.md` with majority/minority reasoning, probe results, final classification, REQ/UC mapping, and whether a regression test is required. Confirmed bugs become `BUG-NNN`; hardening items remain distinct and must not inflate bug counts.

## Completion Gate

- All candidates and all 14 requirements reviewed.
- Documentation contradictions are assigned an owner and authoritative source.
- Every confirmed code bug has executable evidence and regression-test target.
- Every disagreement has a recorded probe rather than prose voting.
- Security findings separate exploitability, prerequisites, and defense-in-depth.
