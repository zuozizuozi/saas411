## Confirmed Structural Bugs

- HIGH: Stripe return URL literal `/dashboard` has no page implementation (`src/services/billing.ts:140-146`, `269-304`) → BUG-001.
- HIGH: QStash reconciliation stops nonterminal after ten attempts and the failure callback logs only (`src/app/api/internal/workflows/video-reconcile/route.ts:28-43`) → BUG-002.
- MEDIUM: Provider representations disagree at callback ingress (`src/app/api/v1/video/callback/[provider]/route.ts:16`) → BUG-003.
- MEDIUM: AI callback lacks the byte-limited reader used by Stripe (`src/app/api/v1/video/callback/[provider]/route.ts:40`) → BUG-004.
- MEDIUM: executable callback-secret name and active guides disagree → BUG-005.
- LOW: emitted Vercel observability scripts violate configured CSP → BUG-006.

## Questions, Not Bugs

- Q-001 DNS rebinding: `assertSafeRemoteMediaUrlResolved()` validates one DNS result, while `fetch()` may resolve again (`src/lib/storage.ts:72-79`, `104-108`). Code-level TOCTOU exists, but actual exploitability and the correct undici dispatcher/pinning design need a focused environment probe.
- Q-002 Batch revocation race: `freezeMany()` precedes per-output `generate()` calls; a policy change between those points could throw before the inner submission catch. Inputs are prevalidated and the race is narrow; a deterministic concurrency reproducer is required before BUG classification.

## Verified-Safe Structural Areas

- Authenticated principal comes from Better Auth headers; admin role is re-read from the database (`src/lib/api/auth.ts:10-41`, `src/lib/auth/admin-role.ts:12-19`).
- Admin endpoints that use server component helpers still call database-backed `isAdmin()`; the apparent public grep results were false positives.
- User video queries and mutations include `userId`; generation images call `assertOwnedImageUrls()`.
- Shared model catalog is enforced again by `validateGenerationParams()` before credit calculation/provider routing.
- Credit mutations use user advisory locks and conditional HOLDING→SETTLED/RELEASED claims (`src/services/credit.ts:359-513`).
- Stripe webhook uses a 1 MiB reader, signature verification, event claim, and order-number idempotency.
- Remote media already rejects HTTP/private networks, revalidates redirects, enforces timeout, and bounds streamed bytes.
