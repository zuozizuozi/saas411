# BUG-002: Durable reconciliation abandons nonterminal tasks
> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-08-04 · Project: VideoFly

## Summary

The durable workflow polls only ten times and returns PENDING at `src/app/api/internal/workflows/video-reconcile/route.ts:28-43`. A missed callback plus provider latency beyond roughly 7.5 minutes can leave the video and credit hold nonterminal.

## Spec reference

- Requirement: REQ-007
- Spec basis: `quality/REQUIREMENTS.md:91-103`
- Behavioral contract quote: "requeued, explicitly timed out, or escalated to a persistent recovery queue"

REQ-005/REQ-007 require missed callbacks to reach a terminal result or persistent recovery action. Contract: “no accepted paid generation is abandoned with frozen credits.”

## The code

The loop sleeps 45 seconds after each attempt, then returns a nonterminal object. The failure callback at `video-reconcile-failed/route.ts:20-25` records only a log.

## Observable consequence

If the provider keeps processing after the workflow window and no callback/user poll arrives, the database remains GENERATING and the hold remains HOLDING indefinitely.

## Depth judgment

Callbacks and active user polling mask this defect. It appears specifically when the callback is lost, the task is slow, and the user leaves—exactly the degradation path the durable workflow claims to cover.

## The fix

The proposed patch extends the policy to 60 minutes and then invokes the existing idempotent failure/release path. Phase 4 must confirm the business timeout before application.

```diff
-      for (let attempt = 0; attempt < 10; attempt += 1) {
+      for (let attempt = 0; attempt < 80; attempt += 1) {
@@
-      return { status: "PENDING", reason: "reconciliation-window-exhausted" };
+      return context.run("fail-video-after-provider-timeout", () =>
+        videoService.failGeneration(context.requestPayload.videoUuid,
+          "Provider did not reach a terminal state within 60 minutes")
+      );
```
