# BUG-006: CSP blocks emitted Vercel observability scripts
> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-08-04 · Project: VideoFly

## Summary

`src/app/layout.tsx:124-125` emits Analytics and Speed Insights, but `next.config.mjs:17` omits `va.vercel-scripts.com` from `script-src`. Browser exploration reproduced CSP blocks.

## Spec reference

- Requirement: REQ-014
- Spec basis: `quality/REQUIREMENTS.md:191-200`
- Behavioral contract quote: "intentionally enabled diagnostics to load"

This is an operational observability contract rather than a core functional REQ: intentionally enabled diagnostics must load under the application's CSP.

## The code

The CSP allows Stripe and Vercel Live but not the origin used by both emitted Vercel observability scripts.

## Observable consequence

Analytics and performance measurements are not collected, reducing evidence during production incidents. Core generation still works.

## The fix

Allow the exact script origin if these integrations are intentionally enabled.

```diff
-  `script-src 'self' ... https://js.stripe.com https://vercel.live`,
+  `script-src 'self' ... https://js.stripe.com https://vercel.live https://va.vercel-scripts.com`,
```
