# BUG-005: Callback-secret documentation mismatch
> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-08-04 · Project: VideoFly

## Summary

README and the API integration guide configure `AI_CALLBACK_SECRET`, while executable code reads only `CALLBACK_HMAC_SECRET` at `src/ai/utils/callback-signature.ts:6-13`.

## Spec reference

- Requirement: REQ-012
- Spec basis: `quality/REQUIREMENTS.md:164-174`
- Behavioral contract quote: "All active deployment documentation names `CALLBACK_HMAC_SECRET` consistently."

REQ-012 requires active deployment documentation to match executable configuration. Contract: “deployment instructions use `CALLBACK_HMAC_SECRET` consistently.”

## The code

`.env.example` is correct, but two prominent guides contain a different variable name that is never read.

## Observable consequence

A deployment following those guides fails when generation attempts to create a signed callback URL.

## The fix

Replace the stale variable name in both guides.

```diff
-AI_CALLBACK_SECRET=your_callback_secret
+CALLBACK_HMAC_SECRET=your_callback_secret
```
