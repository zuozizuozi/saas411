# BUG-009: QStash scheduler accepts credentials that its receiver rejects
> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-08-05 · Project: VideoFly

## Summary

`isWorkflowEnabled()` and `scheduleVideoReconciliation()` accept token plus app URL even though the receiving workflow refuses every request without both QStash signing keys.

## Spec reference

- Requirement: REQ-007
- Spec basis: `quality/REQUIREMENTS.md:91-103`; `quality/REQUIREMENTS.md:164-174`
- Behavioral contract quote: "schedule a signed durable reconciliation when production queue configuration is present"

## The code

At `src/lib/upstash.ts:9-27`, enablement and publication require only `QSTASH_TOKEN` and `NEXT_PUBLIC_APP_URL`. At `src/app/api/internal/workflows/video-reconcile/route.ts:18-24`, the receiver also requires `QSTASH_CURRENT_SIGNING_KEY` and `QSTASH_NEXT_SIGNING_KEY` or returns 503.

## Observable consequence

A partially configured deployment can publish reconciliation jobs to an endpoint guaranteed to reject them. The configured failure callback uses the same missing signing keys, so missed provider callbacks can retain frozen credits without a working recovery path.

## Depth judgment

Both halves validate configuration locally, but they validate different sets; the failure appears only across the scheduler/receiver authentication boundary.

## The fix

Use one complete configuration predicate for enablement, client creation, scheduling, and receiver readiness.

```diff
+function getWorkflowConfig() {
+  const config = {
+    token: process.env.QSTASH_TOKEN,
+    appUrl: process.env.NEXT_PUBLIC_APP_URL?.replace(/\/$/, ""),
+    currentSigningKey: process.env.QSTASH_CURRENT_SIGNING_KEY,
+    nextSigningKey: process.env.QSTASH_NEXT_SIGNING_KEY,
+  };
+  const configured = Object.values(config).filter(Boolean).length;
+  if (configured > 0 && configured < Object.keys(config).length) {
+    throw new Error("Incomplete QStash workflow configuration");
+  }
+  return config;
+}
@@
-  return Boolean(process.env.QSTASH_TOKEN && process.env.NEXT_PUBLIC_APP_URL);
+  return Object.values(getWorkflowConfig()).every(Boolean);
```
