# Product shell specification

- Reference viewport: desktop 1440px, tablet 768px, mobile 390px.
- Desktop: fixed 224px sidebar on `#030712`, 1px `#1f2937` divider, compact 40px navigation rows.
- Mobile: 52px sticky top bar with menu, locale, login and primary signup action.
- Brand remains VideoFly. Only two creation routes are exposed: text-to-video and image-to-video.
- Secondary routes: creations/history and pricing. Image generation and reference-video routes are excluded.
- Active navigation uses a subtle blue-violet fill and white text, not a large gradient card.
- Keyboard focus is always visible; icon-only controls have accessible names.
