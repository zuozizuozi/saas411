# Home hero specification

- Full viewport cinematic background video, autoplay, muted, loop and playsInline.
- Strong black/blue gradient overlays preserve text contrast and provide a poster-color fallback.
- Centered VideoFly headline, concise supporting copy and two bordered actions for image-to-video and text-to-video.
- Desktop keeps the hero near 720px; mobile uses at least 760px and places actions vertically.
- Video URL is centralized in showcase configuration so it can be replaced by the user's R2 asset without component edits.
- Reduced-motion users see the poster/background rather than forced animation.
